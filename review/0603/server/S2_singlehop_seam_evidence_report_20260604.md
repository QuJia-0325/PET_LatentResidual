# S2.0 single-step 逐跳 seam 证据

日期: 2026-06-04

## 判读

- 弱支持 D50→D20 排名最坏，但不支持数量级最坏叙事。
- 首跳 latent RMS 比例: 2.062。
- 首跳 σ·dt 比例: 1.962。
- 首跳 V13 single-step seam 比例: 1.084。
- 首跳 V13 single-step ext-seam 比例: 1.487。

## 口径

- 每个 hop 用对应 GT source latent 单步预测 GT destination；非 hop0 不使用 pixel forcing。
- seam/ext-seam 在 clip3 SUV [0,3] 域计算；PSNR 仍使用 `calc_psnr_clip3`。
- 这是 S2.0 的更严格口径，避免 cascade endpoint 把早期误差传播到后续 timepoint。
