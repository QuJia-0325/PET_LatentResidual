# S2.0 逐跳 seam 证据报告

日期: 2026-06-04

## 判读

- S2.0 只支持弱版叙事：首跳在 latent 位移、σ·dt 与 V13 endpoint seam 上排名第一，但没有达到任务文件要求的数量级优势。论文中不能写成“首跳显著/数量级最坏”，只能写成“首跳最高、但差距有限”。
- 首跳 latent RMS 相对其它最强跳比例: 2.062。
- 首跳 σ·dt 相对其它最强跳比例: 1.962。
- 首跳 V13 destination seam 相对其它最强跳比例: 1.151。

## 口径与限制

- latent 位移直接从 `latents_val.pt` 的 GT latent 差分计算；`σ·dt` 来自当前 A4/V13 共享配置。
- seam/ext-seam 读取既有 full-val B-ext per-slice CSV，使用 destination endpoint 的 clip3 SUV seam；这验证逐跳 endpoint seam 风险，不等同于显式构造 `J_G(z_dst-z_src)` 响应。
- 若要验证 `M=JᵀJ` 与 patch seam 的几何桥接，仍需 S2.a/S2.b/S2.c；但根据任务停机规则，应先确认 S2.0 是否支持经验叙事。
