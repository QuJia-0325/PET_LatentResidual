## 1. 致命问题（会让我们走错方向 → 必须修）

### F1. 单点 best 当信号 → 可能放弃了一个其实有用的方向
原报告 §4.2 Finding A：V3 baseline 0.000567 → V4 best 0.000538，称"5% 边际正向"。

**风险**：如果这 5% 是 val 自然波动里抽到的好运点，我们会因为"小改进"自我安慰；如果它真是 SF 在低 α 区的稳定收益，我们会因为"小"而放弃 → **后者才是医生角度最大的损失**：normal 档 MSE 从 0.000175 降到 0.000170 看起来 2.9%，但落到像素域可能就是医生能看出的边缘清晰度差异。

**必做的事**（不是为了发文章，是为了不错过方向）：
1. 把 step 87200~91800 这段 **α=0 的 val 点** 全部列出来，看 val_chain_normal_mse 自然波动是 ±多少
2. 看 step 92800（α≈0.10）这一点的 normal_mse=0.000170 是不是**稳定低于自然波动下沿**
3. 如果是 → SF 低 α 区是真信号，值得做 ablation；如果不是 → 才能说"无差异"

**我之前的措辞错在哪**：直接说"撤回改进结论"也是过度反应。正确的是"先把波动范围测出来再判断"。

### F2. "方法本身缺陷" 这个判断下早了
原报告 §5 表格说 V4 修复后能区分"schedule bug vs 方法缺陷" → 不能。

**原因**（与医生需求直接相关）：
- ramp_steps=10000、α_end=1.0、SF loss 权重、optimizer LR 在 ramp 期间没缩 — 任何一个动一下，α=0.18 那个崩溃点都可能消失
- α=0.30 时 val_select 反而比 α=0.22 好（0.000654 vs 0.001025）→ **这本身就是"超参不稳"而非"方法不行"的强证据**。如果是方法本身在 α 高时一致失败，应当单调恶化，但实测是震荡的

**对医生效果的含义**：现在就把 SF 路线判死，等于没排查就丢掉一个候选。即便我们最终不用 SF，也要先知道它失败的真实原因，否则下一个类似 idea（teacher forcing / consistency loss / EMA-pair）会重蹈覆辙。

**修正**：把所有"SF 方法本身有缺陷"改成"当前超参配置下 SF-pair 失效，且失效模式呈震荡而非单调，提示是优化不稳而非损失形式错误"。

### F3. sf_gap 论证链断裂 → 错误归因风险
原报告 §4.3 把 "sf_gap 不收敛" 当成 SF 没用的核心证据，但：
- sf_gap 计算口径报告里没贴公式
- 训练时模型还在走，gap 稳态不等于"模型没学"
- §6 H4 自己已经写"sf_gap 度量本身可能有问题"

**风险**：基于一个未验证的指标做"方法没用"的判断 → 下次设计 self-forcing 类损失时还会犯同样错。

**必做**：去 train_first_hop.py 翻 `compute_self_forcing_z_src` 附近，把 sf_gap 的实际计算式贴出来；在确认前，sf_gap 段降级到"现象"而不是"诊断"。

### F4. val_pair_total 跳变可能是定义本身造成的
原报告 §4.2 Finding C 把 val_pair_total 0→0.0002 当作"SF 把模型推离 GT 的肉眼可见证据"。

**反驳**：val 端 pair loss 计算很可能也乘 sf_alpha；α=0 时 val_pair_total ≡ 0 是**定义恒等式**，不是模型分布漂移信号。

**必做**：查 eval / val hook 里 pair_total 怎么算的，确认是不是 `α × something`。在确认前，Finding C 不能作为"SF 损害模型"的论据。

## 4. 反向意见：与"放弃 SF 路线"的供述对赌

我作为 supervisor 不同意原报告的隐含判决"SF-pair 应放弃"。**理由直接挂钩医生需求**：

1. **α=0.10 时 normal_mse 是这一整段 V4 训练里最低的**（0.000170 vs baseline 0.000175）。即便统计上不显著，也没有任何反向证据说它有害。
2. **α=0.30 比 α=0.22 还好**（select 0.000654 vs 0.001025）→ 这个非单调性本身就指向"训练动力学问题"，不是"损失方向错"。
3. 如果我们因为 8400 步的单 seed 单超参实验就否决一个方向，那项目里没有任何方向能站得住。

**真正想知道的事**（按对医生效果的影响排序）：
- Q1：α∈[0.05, 0.15] 的窄区间，长训稳定后 normal_mse 能不能稳定在 0.000160 以下？
- Q2：失败是 ramp 太陡（LR 没跟上）还是 loss 形式错？做一组 ramp_steps=30000 + α_end=0.15 的实验就能区分。
- Q3：sf_gap 真实定义是什么？如果是非归一化的 L2，那它的"不收敛"是无信息量的。

**这三个问题没回答前，"放弃 SF" = 把可能的医生满意度提升白白丢掉。**
